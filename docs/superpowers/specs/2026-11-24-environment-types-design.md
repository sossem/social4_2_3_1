# 설계: 우리를 둘러싼 환경 (사회 4학년 3단원 1 — 교과서 98~99쪽)

- 저장소: `sossem/social4_2_3_1`
- 앱 이름(가칭): **우리 동네 환경 탐험대**
- 작성: 2026-11-24, 교사 확인 대기

## 1. 의도

교과서 98~99쪽 「우리를 둘러싼 환경에는 어떤 것들이 있을까요?」 차시를 학생 1명이 기기 1대로 처음부터 끝까지 혼자 하는 웹앱.

교과서의 궁금증("바다도 강도 없는데 호수 물은 어디서 왔을까?")은 이 차시의 핵심과 같다. 그림 ㉮ 호수는 자연이 만들었고 ㉯ 호수는 사람이 만들었다. **같아 보여도 자연이 만든 것과 사람이 만든 것이 있다**는 것이 자연환경·인문환경 구분의 출발점이다. 앱은 비슷한 새 궁금증으로 시작하고, 3단계에서 그 답을 푼다.

학습 목표: 환경의 뜻을 알고, 우리 주변의 환경을 자연환경과 인문환경으로 구분할 수 있다.

## 2. 목표 / 하지 않을 것 / 실패로 보는 것

**목표**
- 교사가 준 수업 흐름 다섯 단계를 그대로 따른다: 도입 궁금증 → 환경의 뜻 → 환경의 종류 → 구분 활동 → 정리 퀴즈.
- 아이들이 자주 틀리는 것을 일부러 많이 다룬다.
  - 논·밭·과수원·비닐하우스: 초록색이라 자연환경으로 착각하기 쉽다.
  - 비·눈·바람·기온: 땅의 모습이 아니라서 환경으로 생각하지 못하기 쉽다.
  - 저수지·방파제처럼 자연처럼 보이는 인문환경.

**하지 않을 것**
- 모둠 기능, 교사용 결과 모아 보기, 로그인, 서버.
- 다음 차시 내용(환경에 따른 생활 모습, 환경의 변화).

**실패로 보는 것**
- 생김새가 헷갈리는 항목(공원의 나무, 그냥 "호수", 제방을 쌓은 강)을 넣어 정답이 둘 다 맞을 수 있게 되는 것.
- 교과서 그림·문장을 그대로 옮기는 것.

## 3. 방식 (고려한 것과 고른 것)

4단계 "구분해 보기"의 방식으로 세 가지를 생각했다.

| 방식 | 장점 | 단점 |
|---|---|---|
| A. 그림 지도에 ○/△ 표시 | 교과서 활동과 같다 | 그림 한 장에 15곳 안팎만 넣을 수 있다 |
| B. 카드 나누기 (끌어다 놓기) | 항목을 30개 넘게 늘리기 쉽다 | 교과서 활동과 모양이 다르다 |
| **A + B (교사 선택)** | 교과서처럼 표시하고, 카드로 연습량을 채운다 | 화면이 하나 늘어난다 |

**교사가 A + B를 골랐다.**

## 4. 정해진 것

- 개인 활동. 태블릿과 PC.
- 기술: HTML·CSS·JS 정적 웹앱, 빌드 없음, `index.html`을 열면 실행. localStorage 저장, "처음부터 다시".
- 글꼴: 눈누 학교안심 둥근미소(제목), 프리텐다드(본문). `edu-webapp:noonnu-fonts`의 검증된 코드를 쓴다.
- 기호: 교과서와 같이 자연환경 **○**, 인문환경 **△**.

## 5. 화면 흐름 (상단에 진행 단계 표시)

### 0. 시작
번호·이름 입력, "탐험 출발". 오늘의 미션 다섯 개:
① 궁금한 연못 ② 환경이 뭘까? ③ 환경의 두 가지 ④ 환경 구분하기 ⑤ 정리 퀴즈

### 1. 궁금해요: 두 연못의 비밀 (도입)
- 새로 쓴 이야기(교과서 이야기와 같은 구조): 동네에 연못이 두 개 있다.
  - 뒷산 숲속 연못: 산에서 흘러내린 물이 모였다.
  - 아파트 단지 공원 한가운데 연못: 분수가 있고, 둘레가 돌로 반듯하다.
- 그림 두 장(SVG)과 질문 "두 연못은 각각 어떻게 생겼을까요?"
- 연못마다 "자연이 만들었어요 / 사람이 만들었어요"를 고르고, 그렇게 생각한 까닭을 한 줄 쓴다. 도움 문장: "~이 있어서 ~이 만든 것 같아요."
- 정답은 여기서 알려 주지 않는다. "답은 ③ 미션에서 찾을 수 있어요."
- 다음 조건: 둘 다 고르고 까닭 쓰기.

### 2. 환경이 뭘까?
- 가운데 탐험대원 그림. "나를 둘러싼 것"을 눌러 하나씩 나타나게 한다(하늘, 산, 비, 바람, 집, 길, 학교, 나무 등 8개, 원 모양으로 둘러쌈).
- 다 나타나면 뜻을 보여 준다: "우리를 둘러싸고 있는 모든 것을 **환경**이라고 해요."
- 확인 문제 2개(OX). 예: "환경은 산과 바다만 말해요."(✕) / "비와 바람도 환경이에요."(○)
- 마지막에 "환경은 크게 두 가지로 나눌 수 있어요" → 다음 단계.
- 다음 조건: 8개 모두 열기, 확인 문제 2개 풀기.

### 3. 환경의 두 가지
- 탭 두 개: **○ 자연환경** / **△ 인문환경**.
- 자연환경: 뜻 "자연 그대로의 환경". 예를 두 묶음으로 보여 준다.
  - 땅의 생김새: 산, 들, 하천, 바다
  - 날씨: 눈, 비, 바람, 기온 ("날씨도 환경이에요!" 강조)
- 인문환경: 뜻 "사람들이 필요한 것을 얻거나 생활을 편리하게 하려고 만든 환경". 예: 논, 밭, 과수원, 항구, 다리, 도로, 아파트.
  - 예마다 뒤집는 카드: "왜 만들었을까요?" → "강을 쉽게 건너려고 다리를 만들었어요."
- 두 탭을 다 보면 1단계의 답을 공개한다: 숲속 연못 = 자연환경 ○, 공원 연못 = 인문환경 △. 내가 고른 답과 나란히 보여 준다.
- 다음 조건: 두 탭 다 보기, 인문환경 카드 7개 모두 뒤집기.

### 4-1. 환경 구분하기: 마을 그림 지도 (A)
- 교과서 99쪽 같은 마을 그림을 새로 그린다(SVG, 원본). 산, 바다, 비구름이 있고, 논·밭·아파트·항구가 함께 있는 마을.
- 표시할 곳 14곳 (`data/places.js`)

  | 자연환경 ○ | 인문환경 △ |
  |---|---|
  | 산, 들, 하천, 바다, 비, 바람(나무가 흔들리는 그림) | 논, 밭, 비닐하우스, 과수원, 아파트, 도로, 다리, 항구 |

- 장소의 이름표를 누르면 아래에 "○ 자연환경 / △ 인문환경" 버튼이 뜬다. 고르면 지도 위에 ○ 또는 △가 그려진다.
- 맞으면 까닭 한 줄. 틀리면 힌트 질문 "이것은 사람이 만들었나요?" 후 다시. 두 번째도 틀리면 정답과 까닭.
- 다음 조건: 14곳 모두 표시.

### 4-2. 환경 구분하기: 카드 나누기 (B)
- 그림 카드를 "○ 자연환경" / "△ 인문환경" 상자로 끌어다 놓는다. 누르고 상자 누르기와 키보드도 지원(`edu-webapp:tablet-ready`의 `pointer-drag.js`).
- 카드 30개 이상 (`data/cards.js`), 4-1과 겹치지 않는 것 위주로 무작위 순서.
  - 자연환경 예: 숲, 섬, 갯벌, 폭포, 동굴, 계곡, 눈, 안개, 기온, 햇빛, 모래사장, 바위산, 화산, 사막, 빙하
  - 인문환경 예: 학교, 시장, 병원, 공원 놀이터, 터널, 댐, 저수지, 방파제, 등대, 기찻길, 공항, 염전, 계단식 논, 공장, 주유소, 정류장
- 놓으면 바로 맞고 틀림과 까닭. 틀린 카드는 제자리로 돌아가 다시 놓는다.
- 다음 조건: 10장 맞게 놓기. 남은 카드는 "더 해 보기".

### 5. 정리 퀴즈
- 10문제 무작위. 문제는 `data/places.js`, `data/cards.js`에서 자동으로 만들고, `data/quiz.js`로 직접 문제를 더할 수 있다.
- 문제 유형
  - 자연환경일까? 인문환경일까? (가장 많이)
  - OX ("논은 자연환경이에요." ✕)
  - 빈칸 채우기 ("사람들이 만든 환경을 ( )이라고 해요.")
  - 까닭 고르기 ("사람들이 항구를 만든 까닭은?")
  - 네 개 중 고르기 ("다음 중 자연환경이 **아닌** 것은?")
- 문제마다 바로 결과와 까닭을 보여 준다. 틀린 문제는 마지막에 다시 푼다.

### 6. 마무리
- 퀴즈 점수와 "환경 탐험대" 배지.
- 나의 기록 모아 보기: 1단계 내 예상과 정답, 그림 지도(내 ○/△ 표시), 카드 나누기 결과.
- 오늘 알게 된 점 한 줄 쓰기.
- 인쇄 / 이미지 저장.

## 6. 데이터

- `data/places.js` → `window.PLACES`: `id, name, type(natural|human), x, y(그림 위 위치), reason, hint`
- `data/cards.js` → `window.CARDS`: `id, name, type, emoji, image(비워 두면 이모지), reason`
- `data/quiz.js` → `window.EXTRA_QUIZ`: `type(choice|ox|blank|reason), question, choices, answer, explain`
- `js/config.js` → `window.CONFIG`: 카드 통과 장수(10), 퀴즈 문항 수(10), 2단계 확인 문제 사용 여부
- 저장 키: `social4-2-3-1-env-v1`

## 7. 디자인

- 분위기: 탐험대 수첩과 마을 지도.
- 색: 자연환경 = 초록 계열 + ○, 인문환경 = 주황 계열 + △. 앱 전체에서 같게 쓴다. 강조색은 교과서처럼 노랑·주황.
- 본문 18px 이상, 버튼 48px 이상, 지도 이름표와 카드는 손가락으로 누르기 쉽게 크게.
- 문구는 `edu-webapp:kid-friendly-copy`를 따른다. 교과서 용어(자연환경, 인문환경, 하천, 항구 등)는 그대로 쓴다.

## 8. 만드는 사람에게 맡긴 것 (내가 정한 것, 교사가 고칠 수 있음)

- 앱 이름 "우리 동네 환경 탐험대"와 도입 이야기(두 연못).
- 2단계의 "둘러싼 것" 8개와 확인 문제 2개.
- 4-2 카드 통과 조건 10장. 처음 제안에서는 카드 나누기를 선택 활동("더 해 보기")으로 말했지만, 연습량을 채우려고 10장은 꼭 하게 했다. `config.js`에서 0으로 바꾸면 선택 활동이 된다.
- 4-1에 "바람"을 넣는다. 날씨도 자연환경이라는 점을 그림 지도에서 확인하게 하려는 것이다. 그림에서는 나무가 흔들리고 바람결 선이 보이게 그린다.
- 헷갈리는 항목은 넣지 않는다: 그냥 "호수"(자연·인공 둘 다 있음), 공원의 나무, 제방을 쌓은 강, 논밭 사이 개울.
- 저수지는 "사람이 둑을 쌓아 물을 모아 둔 곳"이라 인문환경으로 넣는다. 까닭 문구에 이 점을 꼭 쓴다.
