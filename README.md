# 우리 동네 환경 탐험대 — 교사용 안내

초등학교 4학년 사회 「우리를 둘러싼 환경에는 어떤 것들이 있을까요?」(교과서 98~99쪽) 수업용 웹앱입니다.
학생 1명이 기기 1대로 처음부터 끝까지 혼자 진행합니다.

| 미션 | 학생이 하는 일 |
|---|---|
| 1 궁금한 연못 | 뒷산 숲속 연못과 공원 연못이 각각 어떻게 생겼는지 고르고 까닭을 씁니다. 답은 미션 3에서 알려 줍니다 |
| 2 환경이 뭘까? | 나를 둘러싼 것 8개를 하나씩 열어 보고 환경의 뜻을 알아본 뒤 OX 문제 2개를 풉니다 |
| 3 환경의 두 가지 | 자연환경(땅의 생김새, 날씨)과 인문환경을 배우고, 인문환경 카드 7장을 뒤집어 "왜 만들었을까요?"를 확인합니다 |
| 4 그림 지도 | 마을 그림의 14곳에 ○ 자연환경 / △ 인문환경을 표시합니다 |
| 5 카드 나누기 | 카드 32장을 두 상자로 끌어다 놓습니다. 10장을 맞게 놓으면 다음으로 갈 수 있고, 남은 카드는 더 해 볼 수 있습니다 |
| 6 정리 퀴즈 | 10문제를 풀고, 틀린 문제는 마지막에 다시 풉니다 |
| 마무리 | 점수와 배지, 활동 기록, 오늘 알게 된 점. 인쇄하거나 이미지로 저장합니다 |

## 실행 방법

- 서버, 로그인, 설치가 필요 없습니다. `index.html`을 브라우저(크롬, 엣지, 사파리, 웨일)로 열면 바로 실행됩니다.
- 인터넷에서 받는 것은 두 가지뿐입니다.
  - 글꼴(눈누의 학교안심 둥근미소, 프리텐다드): 인터넷이 안 되면 기기의 기본 글꼴로 보입니다.
  - 이미지 저장 기능(html2canvas 1.4.1): 인터넷이 안 되면 "인쇄 → PDF로 저장"을 안내합니다.
- 나머지 기능은 인터넷 없이도 모두 동작합니다.

## 파일 구성

| 파일 | 내용 | 교사가 고칠 일 |
|---|---|---|
| `index.html` | 앱을 여는 파일 | 없음 |
| `js/config.js` | 교사 설정 | 카드 통과 장수, 퀴즈 문항 수, 확인 문제 사용 여부 |
| `data/places.js` | 그림 지도의 14곳 | 까닭과 힌트 문구 |
| `data/cards.js` | 카드 나누기 카드 32장 | 카드 더하기·빼기, 사진 넣기 |
| `data/quiz.js` | 직접 넣는 퀴즈 문제 | 문제 더하기 |
| `css/style.css`, `js/app.js`, `js/art.js` 등 | 화면 디자인과 동작, 그림 | 없음 |
| `tests/` | 개발자용 시험 | 없음 |

파일은 메모장이나 VS Code로 열어 고치고, 저장한 뒤 브라우저를 새로고침하면 적용됩니다.

## 수업 전에 확인할 것

1. **새로 만든 자료입니다.** 미션 1의 두 연못 이야기, 마을 그림, 사례와 까닭 문장은 교과서를 옮기지 않고 이 앱을 위해 새로 만들었습니다. 교과서의 구조(궁금증 → 자연환경과 인문환경 → 그림에 ○/△ 표시)는 따랐습니다.
2. **헷갈리는 항목은 일부러 뺐습니다.** 그냥 "호수", 공원의 나무, 제방을 쌓은 강처럼 자연환경·인문환경 양쪽으로 볼 수 있는 것은 넣지 않았습니다.
3. **저수지는 인문환경으로 넣었습니다.** "사람들이 둑을 쌓아 물을 모아 둔 곳"이라는 까닭을 함께 보여 줍니다. 수업에서 한 번 짚어 주시면 좋습니다.
4. **바람, 비, 눈, 기온, 안개, 태풍, 햇빛은 자연환경입니다.** 날씨도 자연환경이라는 점을 그림 지도와 카드에서 여러 번 확인하게 했습니다.
5. **카드 나누기는 10장이 통과 조건입니다.** `js/config.js`에서 바꿀 수 있습니다(아래 참고).

## 내용 바꾸는 방법

### 카드 더하기 (`data/cards.js`)

```js
{ id: 'forest', name: '숲', type: 'natural', emoji: '🌳', image: '', reason: '숲은 나무가 저절로 자라 이룬 자연 그대로의 환경이에요.' },
```

| 칸 | 뜻 |
|---|---|
| `id` | 영어로 된 이름. 다른 카드·장소와 겹치지 않게 씁니다 |
| `name` | 카드에 보이는 이름 |
| `type` | `natural`(자연환경 ○) 또는 `human`(인문환경 △) |
| `emoji` | 사진이 없을 때 보여 줄 그림 문자 |
| `image` | 사진 주소. 비워 두면 `emoji`를 보여 줍니다 |
| `reason` | 맞게 놓았을 때 보여 줄 까닭 한 줄 |

**사진 넣기**: `images` 폴더를 만들어 사진(예: `images/forest.jpg`)을 넣고 `image: 'images/forest.jpg'`로 씁니다. 인터넷 사진 주소를 써도 됩니다. 저작권과 출처를 확인해 주세요.

### 그림 지도 (`data/places.js`)

까닭(`reason`)과 처음 틀렸을 때 보여 줄 힌트(`hint`)를 고칠 수 있습니다. `x`, `y`는 그림 위 이름표 위치이니 바꾸지 않는 것이 좋습니다. 장소를 더하거나 빼려면 그림(`js/art.js`)도 함께 고쳐야 합니다.

### 퀴즈 문제 더하기 (`data/quiz.js`)

```js
{ id: 'x-ox-paddy', type: 'ox', question: '논은 자연환경이에요.', choices: ['○', '✕'], answer: '✕',
  explain: '논은 사람들이 벼를 기르려고 만든 인문환경이에요.' },
```

- `type`: `ox`(OX), `blank`(빈칸), `reason`(까닭 고르기), `pickNot`(아닌 것 고르기), `kind`(자연/인문 고르기)
- `answer`는 `choices` 중 하나와 글자까지 똑같아야 합니다.
- 퀴즈는 장소·카드에서 자동으로 만든 문제와 이 파일의 문제(최대 2개)를 섞어 냅니다.

## 설정 바꾸는 방법 (`js/config.js`)

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `cardPassCount` | `10` | 카드 나누기에서 맞게 놓아야 다음으로 갈 수 있는 카드 수. `0`이면 선택 활동이 됩니다 |
| `quizCount` | `10` | 정리 퀴즈 문항 수 |
| `step2CheckQuiz` | `true` | 미션 2의 OX 확인 문제를 쓸지. `false`면 빠집니다 |
| `storageKey` | `'social4-2-3-1-env-v1'` | 기록을 저장하는 이름. 바꾸면 모든 기기의 기록이 처음부터 시작됩니다 |

## 학생 배포 방법

- **GitHub Pages(권장)**: 저장소의 Settings → Pages에서 `main` 브랜치를 고르면 주소가 생깁니다. 그 주소를 QR 코드나 학급 게시판으로 나눠 줍니다.
- **폴더 복사**: 폴더 전체를 학생 기기에 복사하고 `index.html`을 엽니다.
- 학생 기록은 **그 기기의 브라우저에만** 저장됩니다. 새로고침해도 남지만, 다른 기기에서는 처음부터 시작합니다. 한 기기를 여러 학생이 쓰면 앞 학생이 끝난 뒤 오른쪽 위 **처음부터 다시**를 눌러 주세요.
- 학생 결과를 모으려면 마무리 화면에서 **인쇄하기**(PDF로 저장 가능)나 **이미지로 저장**을 써서 제출하게 합니다.

## 개인정보

학생이 입력한 번호, 이름, 답은 그 기기의 브라우저(localStorage)에만 저장되고 외부로 보내지 않습니다. 분석 도구나 광고는 없습니다.

## 개발자용: 시험 돌리기

```bash
node --test tests/unit/*.test.js
```

```bash
node tests/e2e/flow.js
```

```bash
node tests/e2e/screens.js
```

`flow.js`는 태블릿 가로 크기에서 처음부터 마무리까지 진행합니다(끌어다 놓기 포함). `screens.js`는 모든 단계를 학교 기기 크기 5가지로 열어 화면을 점검하고 찍습니다. 둘 다 Playwright가 필요합니다.
